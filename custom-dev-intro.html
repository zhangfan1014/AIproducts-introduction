Two more things

传统 BI 之外，正在长出两个新物种。

它们不是"再多做几个功能"，而是让 AI 能接入企业真实数据、生成可运行应用，并持续沉淀为服务资产。

Thing 01

GuanCLI

让企业 Agent 看见 BI，使用 BI。

Thing 02

SuperApp

让 AI 生成的想法变成可托管、可运行、可分享的应用。

GuanCLI

给 Agent 一把进入 BI 的钥匙。

Agent 越来越会推理，但企业数据场景第一步常常卡在：数据在哪、字段叫什么、口径怎么算、有没有权限。GuanCLI 让 Agent 在授权范围内读取 BI 资产，并把它们用于取数、排查和生成。

数据资产感知安全读取取数 + 加工探索式分析生成看板初版
帮我查华东门店销售额和会员消费占比
识别数据集目录
读取字段与指标口径
跨表取数、匹配、筛选
返回可用表格 / 洞察 / 看板初版

SuperApp

从"做页面"升级成"托管一个决策应用"。

超级应用把观远平台能力原子化，叠加应用托管、CLI / Skill、ADK、API 转发，让网页、小型系统、决策系统都能快速构建、集成、发布。

应用托管ADKAPI 网关表单填报LLM 调用动态数据
静态网页 动态数据页面 小型业务系统 决策系统：数据 + Agent + 业务动作

未来的服务形态

定制开发会更像一套持续进化的数据服务。

01

02

Agent 读取 BI 资产

03

生成应用或看板

04

托管到 SuperApp

05

复用为服务资产

对前线来说，新的机会信号会从"能不能改一个功能"，变成"客户是否希望 AI 更懂业务、让数据直接参与流程"。

前线最该问

10 个问题，把机会问出来。

入口与账号

  1. 员工现在从哪个系统入口开始工作？
  2. 是否希望 BI 跟统一登录或门户打通？
  3. 是否希望 BI 嵌入现有门户、工作台或移动端？

数据与流程

  1. 核心数据主要在哪些业务系统里？
  2. 现在有没有人工导入导出、人工同步？
  3. 标准产品当前最不满足的是接入、展示，还是权限流程？

管理与推广

  1. 权限、审批、导出、安全合规有没有特殊要求？
  2. 是否需要预警和订阅主动推送？
  3. 是否有领导驾驶舱、大屏、专题展示场景？
  4. 这个需求是单部门解决，还是未来全公司推广？

内部判断规则

推进要快，承诺要稳。

✅ 可以尽快识别并推进

  • 常见单点登录
  • 常见系统接口对接
  • 门户内嵌、消息推送
  • 常规样式和页面定制

⚠️ 售前 / 研发尽早介入

  • 权限中心深度打通
  • 审批流联动
  • 特殊加密和安全要求
  • 自定义复杂图表

🚫 不要轻易口头承诺

  • 改动标准产品核心逻辑
  • 平台级新能力
  • 大规模行业化定制
  • 核心系统深度耦合项目

统一对外话术

如果客户的诉求不是"单独做一个功能"，而是希望 BI 更好融入现有 IT 环境和业务流程，或者希望 AI 直接参与数据探索和业务动作，这通常就是我们比较擅长的新型服务场景。
