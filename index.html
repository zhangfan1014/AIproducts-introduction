💡 guancli 是什么？

guancli 是一个通过直接调用 BI 系统 API 来操作观远 BI 的命令行工具。只需 guancli auth login 配置一次认证，之后所有操作——查 ETL、看数据集、搜页面、管指标、操作表单——都在终端里一行命令搞定。

🔐 认证方式

  • 用户名密码登录（Token 自动刷新）
  • 直接粘贴 Auth Token
  • 多环境管理（staging/prod 自由切换）

📤 输出格式

  • auto 智能表格 / json 结构化数据
  • csv / excel 导出文件
  • expanded 竖排详情 / table 对齐表格
  • --raw 原始 JSON / --brief 轻量输出

📋 十大命令模块

命令做什么典型用法
guancli auth 认证管理：登录、多环境切换、查看状态 guancli auth login
guancli auth list
guancli etl 智能 ETL：目录树、搜索、查看详情（含节点 SQL 与血缘） guancli etl tree
guancli etl get <id>
guancli ds 数据集操作：目录树、搜索、详情、SQL 查询、带筛选预览 guancli ds preview <id> --filter "city EQ 杭州"
guancli page 仪表板/页面：目录树、搜索、详情（含卡片列表与血缘） guancli page get <id>
guancli card 卡片操作：查看元信息、预览数据、导出 CSV/Excel guancli card preview <id> -f csv -o data.csv
guancli chatbi ChatBI 调用：L1 问数、L2 洞察，支持指定 Agent 模式 guancli chatbi query --theme-name "经营" --message "本月GMV?"
guancli metric 指标管理：搜索、查询、创建/编辑/删除、目录树、公共维度 guancli metric search 营收
guancli metric query <id> --dim 城市
guancli form 表单填报：Airtable 风格 CRUD，支持子表操作 guancli form add <id> --data '{...}'
guancli task 任务排查：查看运行中任务、历史记录、任务详情 guancli task running
guancli app SuperApp：创建项目模板、发布到 BI 平台 guancli app create
guancli app publish

📐 一个典型的工作流：从零到拿到数据，只需几行命令

# 步骤 1
guancli auth login
# 登录认证，一次配置后续无需重复
# 步骤 2
guancli ds search "销售订单"
# 按名称模糊搜索数据集
# 步骤 3
guancli ds preview abc123 --limit 20
# 预览数据集前 20 行，快速了解数据长什么样
# 步骤 4
guancli ds execute-sql -inputs abc123 \ -sql 'SELECT COUNT(*) as total FROM `销售订单`'
# 直接执行 SQL 查询，灵活分析
# 步骤 5
guancli chatbi query --theme-name "经营" \ --message "分析最近30天各品类GMV变化"
# 自然语言问数，中文聊天即可分析

🧭 GuanCLI vs 超级应用：先看清分工
两类能力解决不同问题，了解差异再选方向
方向 解决什么 适合展示的价值
GuanCLI
+ GuanETL / GuanVis		 让 Agent 读取、理解和操作 BI 中的数据集、页面、卡片、ETL 等资产。 自动分析、口径解释、ETL 排查、看板生成、日报写入飞书。
超级应用 把 BI 数据和指标做成业务人员可操作的场景化应用。 筛选、测算、填报、方案生成、大屏展示、消息推送。

🔑 一句话理解

GuanCLI 偏"让 Agent 会用 BI"——自动查数据、解释口径、排查链路；
超级应用偏"让业务在数据里完成动作"——测算、填报、组货、推送，在场景中直接操作数据。

🎯 如何选择使用方向
客户目标优先方向推荐表达
强调 Agent 能使用 BIGuanCLI自动分析、口径解释、ETL 排查、日报生成
强调业务应用体验超级应用测算、填报、组货、异常处理、大屏展示
强调完整闭环GuanCLI + 超级应用先分析 → 沉淀数据集/看板 → 承接业务动作

从"看到问题"到"组织处理"，一个完整的分析-决策-执行闭环。
