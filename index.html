💡 guancli 是什么？

guancli 是一个通过直接调用 BI 系统 API 来操作观远 BI 的命令行工具。只需 guancli auth login 配置一次认证，之后所有操作——查 ETL、看数据集、搜页面、管指标、操作表单——都在终端里一行命令搞定。

🔐 认证方式

  • 用户名密码登录（Token 自动刷新）
  • 直接粘贴 Auth Token
  • 多环境管理（staging/prod 自由切换）

📤 输出格式

  • auto 智能表格 / json 结构化数据
  • csv / excel 导出文件
  • expanded 竖排详情 / table 对齐表格
  • --raw 原始 JSON / --brief 轻量输出

📐 一个典型的工作流：从零到拿到数据，只需几行命令

# 步骤 1
guancli auth login
# 登录认证，一次配置后续无需重复
# 步骤 2
guancli ds search "销售订单"
# 按名称模糊搜索数据集
# 步骤 3
guancli ds preview abc123 --limit 20
# 预览数据集前 20 行，快速了解数据长什么样
# 步骤 4
guancli ds execute-sql -inputs abc123 \ -sql 'SELECT COUNT(*) as total FROM `销售订单`'
# 直接执行 SQL 查询，灵活分析
# 步骤 5
guancli chatbi query --theme-name "经营" \ --message "分析最近30天各品类GMV变化"
# 自然语言问数，中文聊天即可分析

🧩 SuperApp —— BI 内的自定义应用
在 BI 平台内构建定制化业务应用，走 BI 鉴权、用 BI 数据、受 BI 权限管控——前端代码完全自由

💡 SuperApp 是什么？

SuperApp 是观远 BI 平台内的扩展应用框架。它不走仪表板卡片机制，而是让你用完全自定义的前端代码构建应用——想怎么交互就怎么写。鉴权、数据、权限全走 BI 通道，发布到BI 管理中心 > 扩展应用后，BI 用户即可直接使用。

核心定位：BI 平台内的应用开发平台，不是卡片，不是仪表板，是能独立承载业务逻辑的应用。

🔐 鉴权机制

  • 必须配置 BI 账密 + UID Token
  • UID Token 从 BI 域 Cookie 中获取
  • 数据请求走 Vite_BI_Host 后端通道
  • 所有数据访问受 BI 权限体系管控

🛠️ 技术栈与自由度

  • 前端框架不限：Vue / React / 原生 JS 均可
  • UI 完全自定义：不走卡片组件，想画什么画什么
  • 交互完全自定义：筛选、下钻、弹窗、表单、图表任意实现
  • 数据源：BI 数据集 + 自定义 API 双通道

🧰 五大核心能力

1

BI 数据深度集成

直接读取 BI 数据集，支持筛选、聚合、下钻等完整 BI 查询能力。数据权限自动继承 BI 管控体系，无需额外配置。

2

完全自定义 UI 与交互

摆脱仪表板卡片约束——桑基图、关系图、热力图、自定义表单、多级联动、决策树，任何交互逻辑都能实现。

3

外链服务打通

在 SuperApp 内调用飞书消息、企微机器人、邮件等外部服务 API，实现 BI 数据驱动的协作闭环。比如一键推送异常到群聊。

4

AI 辅助开发

通过 Coding Agent 描述需求即可生成前端代码，非开发人员也能参与 SuperApp 构建。专业开发者则可用 AI 加速开发。

5

发布即用，无需部署

guancli app create 创建项目 → guancli app publish 发布 → BI 管理中心生成 SuperApp ID → 用户即可访问。无需额外服务器和域名。

💡 DecideX 是什么？

DecideX 是观远数据全新发布的AI 决策智能平台（Decision Intelligence Platform）。它不是给 BI 加一个聊天框，也不是单纯把大模型接上报表——而是围绕企业决策上下文（Context），打通数据分析、业务上下文与决策闭环三者，构建一个可组装、可调用、可验证、可持续进化的决策系统。

定位：从 AI+BI 数据分析公司，全面转向 AI 决策智能平台公司。过去十年帮企业"看明白数据"，未来十年帮企业"形成决策闭环"。

📖 DecideX 与 GuanCLI、SuperApp 的关系

GuanCLI 是让 Agent 能调用 BI 资产的"手"——查数据、读 ETL、搜指标；
SuperApp 是让业务人员在 BI 内操作数据的"场"——测算、填报、推送；
DecideX 是统筹全局的"脑"——理解上下文、拆解决策、调度 Agent、推动行动、收集反馈。

三者共同构成观远 AI 产品三件套：手（guancli）+ 场（SuperApp）+ 脑（DecideX），形成完整的分析-决策-执行-反馈闭环。

🔑 一句话理解

guancli：让 Agent 会用 BI——自动查数据、解释口径、排查链路；
SuperApp：让业务在数据里完成动作——测算、填报、组货、推送；
DecideX：让企业形成决策闭环——理解上下文、拆解目标、调度执行、持续进化。
